## 구현 항목 체크(기능 체크표)
| 요구사항 | 상태 | 한 줄 메모 |
|---|---|---|
| 1 렌더링 | 구현함 | 배열 list 매개변수대로 카드 렌더링 |
| 2 검색 | 구현함 | 배열 내부 객체 리터럴 형태의 반환값 |
| 3 정렬 3종 | 구현함 | 라디오 박스 값 기준 정렬 |
| 4 보기 필터와 getView | 구현함 | 조건에 맞게 렌더링 하기위한 배열 생성 |
| 5 찜과 저장 | 구현함 | .like 클릭시 토글하여 로컬 스토리지에 해당 영화 제목을 추가/삭제 |
| 6 빈 결과 | 구현함 | list.length === 0이면 카드가 없다는 의미이므로 is-empty을 설정하여 CSS에서 display: block;로 문구를 나타나게 함 |
| 7 상세 대화상자 | 구현함 | (찜버튼 X)카드를 클릭하면 해당 카드의 제목에 해당하는 객체를 찾아 모달과 innerHTML로 렌더링 |
| 8 인라인 이벤트 속성 없음, 콘솔 오류 0 | 구현함 | 모두 JavaScript에서 구현함 |
| 보너스 | 못 함 | 없음 |
 
## 어려웠던 점 3가지와 해결
- 찜 기능 구현 이후 브라우저에서 테스트 시 찜 N편이 새로 렌더링 되지않음 => document.getElementById("likeCount").textContent = liked.length; 를 추가하지않았음 이후 추가하여 해결

- getView() 함수의 존재의의를 잘 이해하지 못함 => 코드 한줄씩 분석하여 조건에 맞게 화면을 렌더링하기 위해 존재하는 함수라는 것을 깨달음

- refresh() 함수 또한 처음에 잘 이해가 가지않았음 => 코드 흐름을 관찰하여 사용자가 정렬등 필터 기능을 사용할때 곧바로 기준에 맞는 화면을 렌더링 하기 위함임을 깨달음
